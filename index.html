Module 3 · Install and Configure Claude Code

  • Target duration: ±4:30
  • Covers: install the app · install Git the right way · Chat, Cowork & Code · connect the project folder

Get the tools onto your computer: install the Claude Code desktop app, install Git the correct way, learn where Chat, Cowork and Code live, and point Claude at the project folder from Module 1. This is the module where careful clicking matters most.

Recorded on the current app version. In the latest desktop app, the sidebar has two icons at the top: Chat and Code (</>). Cowork is no longer a separate tab. It's a Chat | Cowork switch inside the Chat prompt box. The Module 3 brief and the Quick Reference Card still describe three tabs, so they should be updated to match.

Blur the greeting name and email on screen. Don't name a specific model in the narration, since the default changes over time.

Part 2 · Install Git the right way
05 Downloads. Double-click the Git setup file, click Yes, then Next on the licence screen. "Now Git. Most guides online say 'just click Next on everything.' We'll do that too, except for one screen." 15s
06 Click Next through the default screens. Footage sped up 2x, on-screen caption "Keep clicking Next". "Keep clicking Next. The default options are fine. Don't change anything until we reach the screen about the terminal." 15s
07 Screen "Configuring the terminal emulator to use with Git Bash". Zoom in. Select "Use Windows' default console window" and hold for 3 seconds. Amber callout on screen. "Stop here! This is the one that matters. The installer suggests MinTTY. Don't take it. Choose 'Use Windows' default console window' instead. Getting this wrong is the most common reason Claude Code doesn't work later. Double-check it, then click Next." 25s
08 Click Next to the last screen, then Install. Untick "View Release Notes", then Finish. "From here, it's Next all the way, then Install. When it's done, untick the release notes and click Finish." 15s
09 The Finish screen stays visible, no clicks. "Mac users, you can skip all of this. Git is usually already on your Mac. If your Mac ever pops up asking to install 'command line developer tools', just click Install. That's Git." 10s
Part 3 · Chat, Cowork & Code
10 Start menu, open Claude. The app lands on the Chat home screen. Hover over the two icons at the top of the sidebar: the chat bubble and </>. "Let's open Claude again. Look at the top of the sidebar. There are two icons: Chat and Code. Let's see what each one does." 15s
11 Chat home screen. Hover over the prompt box ("How can I help you today?"). Don't type. "Chat is a normal conversation, just like claude.ai. It can't see your files." 10s
12 In the prompt box, click the Cowork side of the Chat | Cowork switch. Hold, then switch back to Chat. "Inside Chat, there's this little switch for Cowork. Cowork is an assistant that works through tasks on its own in the background. Handy, but it's not what we'll use in this course." 15s
13 Click the </> icon at the top of the sidebar. The Code screen opens. "And this is Code, where vibecoding happens. Claude works directly with your project files, and this is where we'll spend the whole course. If it asks you to upgrade, you've signed in with the wrong account. Sign out and use your team email." 15s
Part 4 · Connect your project folder
14 Code screen. Check that Local is selected below the prompt box, then click Select folder…, go to Desktop, choose Claude Projects, and confirm. The folder name appears in the session. "Make sure Local is selected, so Claude works on your own computer. Click Select folder and choose the Claude Projects folder from Module 1. If you skipped that, make the folder on your Desktop first. Claude can only touch files inside this folder." 20s
15 Hover over the model name and effort level next to the send button. Open the dropdown briefly, then close it without changing anything. "Next to the send button is the model and effort level. Leave the default for now. If you ever hit your usage limit, switching to a lighter model is the first thing to try." 15s
16 Click the permission mode button below the prompt box (it shows Accept edits by default). Choose the option that asks before each change. Use the label shown in the current app, for example Ask permissions or Manual. "One more, and this one's important. This button controls how much Claude can do on its own. By default, it applies changes without asking. Switch it to the option that asks you first, so you approve every change. You stay in control." 20s
17 Code screen with the folder selected and an empty prompt box. "That's it! The app's installed, Git's set up the right way, and Claude's connected to your folder. Don't type anything yet. We'll start using it in the next module. See you there!" 20s
